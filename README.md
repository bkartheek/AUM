## 🌌 Why SĀKSHĪ?

Autonomous coding agents (Cursor, Claude Code, Copilot, Cline) are powerful, but they often act like hurried junior developers: jumping directly into code generation, hallucinating file changes, and accumulating memory drift across long sessions.

**SĀKSHĪ** (साक्षी — *The Conscious Witness*) introduces a calm, philosophical, and architectural equilibrium into your workspace:

*   🔒 **Zero Code on Prompt #1**: Deterministic bi-directional protocol requiring intent clarification and approval before any files are modified.
*   ⚡ **Sub-15ms Voice & Acoustic Grounding**: Strips vocal hesitations (*"um", "like"*) and repairs phonetic slips (*"guitar pages" ➔ "github pages"*) grounded against workspace AST symbols in `< 15ms`.
*   🛡️ **Physical Mechanical Lock**: Enforces OS-level write locks (`~/.aum/.intent_locked`) to physically prevent rogue agent file modifications.
*   🧠 **Consciousness Growth Engine**: Serializes every turn into permanent memory impressions (*Saṃskāras*), clustering micro-intents into L1 (Signals), L2 (Workflows), and L3 (Archetypes).
*   🍃 **Pure OS-Level Nervous System**: Lives globally in `~/.aum/`. **Zero** `.aum` folders committed to your git repositories.
