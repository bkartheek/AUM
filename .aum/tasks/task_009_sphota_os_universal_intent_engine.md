# ॐ Saṅkalpa 009: SPHOTA OS — Universal Multi-Intent Engine & Autonomous Guardian

## Paśyantī (The Root Intent & Vision)
Deploy SPHOTA OS: a world-class, bi-directional Intent Operating System that bridges human intent across Cursor, Copilot, Antigravity, Claude Code, Windsurf, and Cline. Features multi-intent DAG disentanglement, speech-to-text noise cancellation, sub-15ms local AST distillation, deterministic `.intent_locked` guards, and an autonomous `sphota_guardian` subagent for continuous learning.

## Madhyamā (The Architecture & Subsystems)
- **Track A: State Engine**: `aum_intent_graph.js` (Macro, Micro, Guard, Parked DAG), branch-aware namespacing, two-tier token anchor (180–380 tokens).
- **Track B: Local Distillation**: Sub-15ms Levenshtein symbol grounder, Mīmāṃsā Ṣaḍ-Liṅga heuristic, Git hooks.
- **Track C: Universal Instrumentation**: `aum install-bridge`, updated `aum_hook.js`, `aum wrap`, and `aum resume`.
- **Track D: Autonomous Guardian**: `sphota_guardian` subagent tracking divergence and learning after every session.
